ℹ️ How it works:

Text spoken on the web app gets converted to Morse code and sent as vibration patterns to your phone. Each vibration corresponds to a dot or dash in Morse code.

• Short vibration = Dot (·)
• Long vibration = Dash (−)
• Pause = Letter separator
